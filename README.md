## English
Have you ever imagined playing a modpack set in a collapsing world overrun by the undead?
Introducing “The Last Survivors”!

This modpack was designed with this map in mind: Mosslorn By: milkshake_mp3. However, I made a few changes to the map to improve the gameplay experience. You can download the modified version through this link: drive.

Of course, nothing stops you from ignoring the map and simply generating a normal world instead. The choice is entirely yours — play however you have the most fun!

### Features:
✔ Custom shop system using Amadron!
✔ Enhanced ambient sounds that are far more realistic!
✔ Extremely optimized!
✔ Machine building!
✔ Over 250 mods!
✔ Several mods that reinforce the zombie threat!
✔ Simple Voice Chat for more realistic and immersive communication between players!
